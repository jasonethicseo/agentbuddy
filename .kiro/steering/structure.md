# Structure

```
/
├─ .kiro/
│  ├─ steering/        product.md, tech.md, structure.md, events.md
│  ├─ specs/           generated by the Kiro spec workflow
│  └─ hooks/           agent hooks (dev hooks + AgentBuddy's own reporting hooks)
├─ src/
│  ├─ core/            pure logic — no fs, network, timers or Date.now()
│  │  ├─ config.ts     shared constants (limits, timings, port parsing)
│  │  ├─ event.ts      BuddyEvent type and validation
│  │  ├─ normalize.ts  raw payload -> BuddyEvent | null, one function per agent
│  │  ├─ history.ts    per-buddy event window: ordering, 50-event cap
│  │  ├─ state.ts      per-buddy state fold, time-based states, buddy view
│  │  ├─ progress.ts   tasks.md text -> { done, total }; spec path check
│  │  └─ text.ts       truncation and status message wording
│  ├─ hook/
│  │  └─ cli.ts        agentbuddy-hook entry: read payload, normalize, POST, exit 0
│  ├─ relay/
│  │  ├─ main.ts       agentbuddy entry: token, restore, listen, clock tick
│  │  ├─ home.ts       ~/.agentbuddy paths, token file, daily log names
│  │  ├─ server.ts     HTTP on 127.0.0.1, token check, routes
│  │  ├─ store.ts      in-memory state + daily events log append and restore
│  │  ├─ stream.ts     Server-Sent Events
│  │  └─ tasks.ts      reads tasks.md for Kiro progress
│  ├─ ui/
│  │  ├─ main.ts       entry; picks relay mode or demo mode
│  │  ├─ screens/      buddy list, message pop-up, inbox, settings
│  │  ├─ sound.ts      Web Audio "ding"
│  │  └─ styles/
│  └─ setup/
│     └─ snippets.ts   prints hook snippets for Kiro, Claude Code, Codex
├─ demo/
│  └─ events.json      recorded, sanitized events for the demo build
├─ tests/
│  ├─ fixtures/        sanitized raw payloads (from events.md)
│  ├─ unit/
│  └─ property/
├─ LICENSE             MIT
└─ README.md
```

## Rules
- `src/core` must not import from `hook`, `relay`, `ui` or `setup`.
- Only `src/hook` and `src/relay` touch the file system or network. Only `src/ui` touches the DOM.
- Time is always passed in as a parameter to core functions.
- Keep each file under about 200 lines; split when it grows.
- Never add `/.kiro` or any of its subfolders to `.gitignore` (submission requirement).
- Never commit real home paths, user names, session IDs or tokens. Fixtures and demo events use `/Users/dev/...` and shortened IDs.
- This is a new project. Do not copy code from other repositories (including the builder's earlier projects). Third-party libraries are listed in README.
